# Reports domain

Multi-section, cited reports generated asynchronously from retrieved evidence, plus PDF export.
A report is requested (queued), generated by a worker through a fixed LangGraph pipeline, and
either becomes **ready** (sections + resolved citations + generation metadata) or **failed**
with an honest reason — never an empty-but-successful report. A ready report can be exported to
a PDF, downloaded through an ACL'd path.

It consumes only existing ports: the permission-aware retriever (`search.SearchService`), the
LLM gateway (`ai`), object storage (`shared.storage`), and the job queue (`shared.queue`).

## Public service interface (`service.py`)

- `ReportService.create / get / list` — request a report (enqueues generation after commit),
  read/list the actor's **own** reports (non-owner / cross-org → 404, no oracle).
- `ReportExportService.create / get / resolve_download` — idempotent PDF export per
  (report, format); `resolve_download` ACL-checks and returns the **storage key** to stream (a
  non-owner / cross-org / not-ready export is a 404 — never another tenant's bytes).

HTTP: `POST /reports` (202), `GET /reports[/{id}]`, `POST /reports/{id}/exports` (202),
`GET /reports/{id}/exports/{export_id}`, `GET …/download` (streams from storage).

### Generation pipeline (`graph/`, ADR 0017)

A **fixed, linear** LangGraph: `knowledge_agent → report_agent → END`, no dynamic routing.
Node 1 retrieves + assembles grounded context (no LLM); node 2 makes one structured call
(`response_schema = ReportContent`) and ground-validates sections. Terminals are typed STATE
(`error`): a content report, `INSUFFICIENT_EVIDENCE` (node 1, too few permitted sources, zero
spend), or `NO_GROUNDED_SECTIONS` (node 2, no section survived grounding). Errors are never
escaping exceptions; an infra failure propagates as a typed `AppError` and is retried by the
worker — never conflated with a content decline.

### Export pipeline (`export_worker.py`, `pdf.py`, ADR 0018)

A worker claims the export (CAS), renders the report `content` + resolved citations +
generation-metadata footer to a PDF with **fpdf2** (no system deps), streams it to storage at
`org/{org_id}/report/{report_id}/{export_id}.pdf`, and marks it ready. Citations render as
`[n] filename, p.X`; the footer carries model · prompt version · generated-at.

## Invariants

- **Cite-or-drop, honest failure.** Every section carries ≥1 citation marker (schema-enforced);
  phantom markers are stripped and an all-phantom section is dropped. If no section survives,
  the report ends FAILED with `NO_GROUNDED_SECTIONS` — exercised explicitly by the report eval.
- **Fixed graph (ADR 0017).** No model-decided routing in V1; nodes are independently
  unit-tested; one structured call per report (budget-safe).
- **Idempotent workers (patterns §7).** Generation and export both: CAS claim
  (`UPDATE … WHERE status = :expected`), bounded retry via `attempt_count`, a sweeper for rows
  orphaned by dead workers, and a user-visible terminal state (FAILED + reason). The export
  render is **deterministic** (fixed PDF creation date — see below), so a sweeper-recovered
  re-export is byte-identical (content-hash asserted).
- **ACL'd download.** `resolve_download` re-checks ownership + tenant before returning a key;
  the isolation suite proves a cross-org / non-owner download is a 404 and never yields another
  tenant's stored bytes. Citation hydration resolves only to permitted chunks (Phase-2
  guarantee re-proven through the report knowledge node).
- **Tenant scoped.** `org_id` on every row (RLS + predicate); raw-count RLS proof on `reports`
  and `report_exports` in the isolation suite.

## Known limitations / notes

- **The PDF's internal `/CreationDate` is fixed (`2020-01-01Z`) for byte-determinism — it is NOT
  the report's generation time.** Do not read `/CreationDate` as "when the report was made"; the
  real generation time is the report row's `created_at` / the metadata footer's generated-at.
  The fixed date is purely so identical `content` renders to an identical PDF (idempotent
  re-export). See ADR 0018.
- **Single structured call per report** (no multi-pass / self-revision in V1, ADR 0017).
- **Provisional generation quality.** The eval gates harness + pipeline correctness against the
  stub, not real-model section quality (ADR 0013 caveat).
